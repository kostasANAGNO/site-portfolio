MY PROJECTS

XkeywordScraper

A keyword-based scraper for X (Twitter) built with Python and Selenium. It collects tweets for a list of keywords within a given date range.

  • Splits the date range into 30-minute windows to collect more tweets per search
  • Authenticates with a session token and can run headless
  • Saves results to JSON named after the keyword and timestamp
  • Optional MySQL storage (V2) and language detection with langdetect
  • Built-in delays and retries to respect rate limits
  • Python
  • Selenium
  • MySQL
  • JSON

Reddit-Data-Extractor

A Reddit scraper built on the PRAW API wrapper that collects posts and comments from chosen subreddits and stores them as CSV files ready for analysis.

  • Covers the top, controversial, new, hot and rising categories with time filters
  • Fetches up to 2000 posts per category in batches
  • Stores post metadata (title, author, score, upvote ratio, comment count) and full comment trees
  • Skips already saved post IDs to avoid duplicates between runs
  • Waits between requests to stay within API rate limits
  • Python
  • PRAW
  • Reddit API
  • CSV

DataMiningProject

A machine learning project that predicts whether a patient has had a heart attack, using a health survey dataset of patient records.

  • Exploratory analysis, including a US state heatmap of heart attack cases
  • Feature engineering: binary, ordinal and one-hot encoding, and state-to-region mapping
  • PCA dimensionality reduction (3D visualisation, 20 components for modelling)
  • KNN classifier: 93.3% accuracy
  • Logistic Regression: 94.6% accuracy, ROC AUC 0.88; strongest predictors are angina, age and stroke history
  • Python
  • pandas
  • scikit-learn
  • seaborn
  • PCA

BitcoinSimulation

An educational blockchain simulation in Python where multiple miner processes race to solve a proof-of-work challenge while the others validate the winning nonce.

  • SHA-256 block hashing, deterministic transaction hashing and Merkle roots
  • Proof-of-work mining with configurable difficulty and automatic difficulty adjustment
  • Multiprocessing miner race with a consensus step before a block is accepted
  • Full-chain integrity validation
  • Command-line demo and unit tests using only the Python standard library
  • Python
  • Multiprocessing
  • Blockchain
  • SHA-256
  • unittest

DeepLearning_MLP_KAN

A comparative study of Kolmogorov-Arnold Network (KAN) and MLP classification heads for weather image classification across 11 classes.

  • Transfer learning with a pretrained MobileNetV3-Large backbone, in two phases: frozen base, then partial fine-tuning
  • Class-weighted training and a 70/20/10 train/validation/test split
  • Test accuracy: KAN head 93%, MLP head 91%, custom CNN baseline 75%
  • Per-class reports, confusion matrices and sample predictions
  • Python
  • TensorFlow / Keras
  • MobileNetV3
  • KAN
  • CNN
